fix adblocker: cache to disk, graceful offline fallback, background refresh

Startup no longer hard-fails when filter-list fetch errors at boot.

Resilience model:
- Use the library Caching interface to persist the compiled binary under
  userData/adblocker-cache.dat after first successful fetch.  Subsequent
  startups deserialize from disk with no network round-trip.
- If both cache and fetch fail, fall back to a small bundled filter list
  so the blocker is always initialised with baseline protection.
- After init, schedule a daily background refresh.  On success the cache
  is replaced atomically via rename.  On failure the old cache stays and
  a retry is scheduled with exponential backoff capped at 8h.
- cleanupAdblocker clears the refresh timer on app quit.

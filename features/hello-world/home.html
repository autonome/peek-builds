What is a tile?

A tile is an HTML file that runs in a dedicated renderer process. It registers commands, can show/hide itself, subscribe to pubsub events, and read/write the datastore. Everything happens through window.app.

Two axes: residency (resident = loaded at startup; lazy = loaded on first use) and visibility (shown/hidden at runtime via showSelf()).

Creating a tile

Minimal manifest (manifest.json) for a resident tile:

{
  "manifestVersion": 2,
  "id": "my-tile",
  "name": "My Tile",
  "tiles": [{
    "id": "home",
    "url": "home.html",
    "width": 700,
    "height": 500,
    "resident": true    // loaded at startup, hidden
  }],
  "capabilities": {
    "commands": true
  }
}

Use resident: true when the tile needs to be instantly available (e.g. invoked by a command). Use lazy (default) when the tile is loaded on first use — saves memory for rarely-used tiles.

Minimal home.html
const api = window.app;
await api.initialize();

api.commands.register({
  name: 'my tile',
  description: 'Open my tile',
  execute: async () => {
    await api.window.showSelf();
    return { output: 'shown', mimeType: 'text/plain' };
  }
});

Call api.initialize() first — it establishes the IPC token and resolves capabilities. Register commands after init. showSelf() reveals this tile's window instantly (no capability required).

Add theme styles by putting this at the top of your CSS:

@import url('peek://theme/variables.css');

Then use tokens like var(--base00) (bg), var(--base05) (text), var(--base0D) (accent). See features/theme-basic/variables.css for the full list.

Debugging a tile

Open DevTools: launch the tile, then open Features Manager (manage features command) and click the tile's devtools button. Or use the Debug Info tab in this tile to inspect the api surface live.

console.log: output appears in the tile's DevTools console (not the main-process terminal). Use console.error to also surface output in the Electron main process log.

Reload after changes: close and reopen the tile window, or use Cmd+R in the focused tile DevTools.

i The Debug Info tab (above) shows api method availability, init result, datastore shape, and pubsub round-trip — run it whenever something is unexpectedly undefined.
Testing a tile

Unit tests — pure logic, no Electron needed:

yarn test:unit

Electron integration tests — full app, headless:

yarn test:electron:bg   # background, logs to /tmp/test-electron.log
yarn test:electron      # foreground headless

Minimal Playwright test for a tile command:

test('hello command shows window', async ({ page }) => {
  await runCommand(page, 'hello');
  const win = await app.waitForWindow('Hello World');
  await expect(win).toBeDefined();
});
i Never use npx playwright test directly — it steals focus. Use yarn test:electron:bg or yarn test:electron:x to stop on first failure.
